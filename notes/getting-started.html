Documentation

Follow these steps to expand the hub:

1. Create Module

Add your tool or note as an HTML file in the respective directory.

2. Register Module

Update the navigation data in script.js (root directory):

{ "name": "Module Name", "url": "tools/file.html" }

3. Design Standards

  • Typography: Cambria and Cambria Math first; Source Serif 4 loads as a close reading fallback where those fonts are not installed.
  • Link ../css/eng-hub.css on tool and note pages for shared spacing, type scale, and form styles.
  • Formulas: use MathJax (TeX) for step-by-step math; keep display math in $$ blocks.
  • Maintain the calm neutral palette and generous whitespace; avoid loud accent colors.
  • Build mobile-first: touch-friendly controls (min ~44px height), fluid type, and horizontal scroll for wide equations only inside math blocks.
